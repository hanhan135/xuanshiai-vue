# 红娘管理中心数据简报框架说明

## 本期目标

数据看板只提供服务红娘管理中心首页的布局和接口承载点：欢迎信息、门店数据简报、快捷入口、推广工具与功能入口。它不承担会员管理、财务结算、审核明细或联系方式查询的替代实现。

## 指标呈现规则

在服务端看板接口可用且经过权限校验前，所有指标值统一显示 `--`。前端不根据本地 Mock、页面缓存或参考图推导门店人数、业绩、分成、待审数或约见数。

本期不创建 Mock 明细页，不生成虚拟会员、订单、审核记录、金额或联系方式。点击入口只进入已实现的框架或给出明确的“待服务端接入”状态。

## 接口契约

看板入口为 `GET /matchmaker/management-center/dashboard`，并且只能在访问接口确认 `can_access=true`、岗位为 `active`、订单为 `paid` 后读取。接口响应不应包含超出当前服务红娘门店和岗位范围的数据，更不能包含可用于绕过用户隐私或双方同意门槛的信息。

服务端接入后，指标和明细仍需按岗位、门店、数据范围与动作权限做独立 RBAC 校验，并为敏感读取和写操作保留审计记录。
